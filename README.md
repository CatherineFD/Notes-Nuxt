# Notes — SPA для заметок с Todo-списками

Небольшое SPA-приложение для заметок, реализованное на **Nuxt 3/4**, **Vue 3 Composition API** и **TypeScript strict**.

Каждая заметка содержит название и список задач (Todo). Пользователь может создавать заметки, редактировать их, управлять пунктами Todo, отменять и повторять изменения, а также удалять заметки с подтверждением.

## Возможности

- Главная страница со списком всех заметок.
- Создание новой заметки.
- Редактирование существующей заметки.
- Удаление заметки с подтверждением через модальное окно.
- Добавление, удаление, редактирование и отметка пунктов Todo.
- Undo / Redo изменений на странице редактирования.
- Автосохранение черновика редактирования.
- Восстановление незавершённого редактирования после случайной перезагрузки страницы.
- Обработка несуществующих URL заметок.
- Адаптивная вёрстка без UI-библиотек.
- Собственные модальные окна с focus-trap, закрытием по `Escape` и полной работой с клавиатуры.

## Стек

- [Nuxt 3/4](https://nuxt.com)
- Vue 3 Composition API
- TypeScript strict
- Pinia
- SCSS / SASS
- Vitest
- Docker / Docker Compose

## Запуск локально

### Требования

- Node.js 20+
- npm 10+

### Установка зависимостей

```bash
npm ci
```

### Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу:

```txt
http://localhost:3000
```

### Production-сборка

```bash
npm run build
npm run preview
```
## Запуск через Docker

### Требования

- Docker Engine 24+
- Docker Compose v2

Проверить, что Docker доступен:

```bash
docker version
docker compose version
```

### Сборка и запуск

Из корня репозитория выполните:

```bash
docker compose up --build
```

При первом запуске Docker соберёт образ приложения. После успешного старта откройте:

```txt
http://localhost:3000
```

### Запуск в фоновом режиме

```bash
docker compose up -d --build
```

### Просмотр логов

```bash
docker compose logs -f
```

### Остановка приложения

```bash
docker compose down
```

### Остановка с удалением volumes

```bash
docker compose down -v
```
